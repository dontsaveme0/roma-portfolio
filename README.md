# Портфолио Ромы Жигарёва

Самостоятельная копия опубликованного сайта **romazhigarev.ru**, перенесённая 14 ноября 2026 года. Вёрстка и содержание взяты из текущего опубликованного Readymag. Макеты Figma сверены как дополнительный источник: они содержат и более ранние варианты.

## Публикация на GitHub Pages

Репозиторий: https://github.com/dontsaveme0/roma-portfolio. Основной адрес: **https://romazhigarev.ru**.

Workflow `.github/workflows/pages.yml` собирает и проверяет сайт при каждом обновлении `main`, затем публикует только содержимое `dist/` через GitHub Pages. Устанавливать зависимости не требуется. В настройках репозитория **Settings → Pages → Source** должен быть выбран **GitHub Actions**, а в **Custom domain** указан `romazhigarev.ru`. Файл `CNAME` включается в сборку; для GitHub Actions домен также требуется указать в настройках Pages.

DNS-записи корневого домена у регистратора R01 должны указывать на GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Для `www` используется CNAME `dontsaveme0.github.io`. HTTPS включается после проверки DNS и выпуска сертификата GitHub.

После изменений выполните `npm run build` и `npm run check`, затем сохраните изменения коммитом и отправьте `main` в GitHub. Результат публикации отображается во вкладке **Actions**.

## Google Analytics

Опубликованный сайт использует прежний ресурс GA4 **Roma Zhigarev** (ресурс `503034001`, поток **Portfolio** `12094530030`, идентификатор `G-MPVN1TELR3`). Его история сохраняется после переноса с Readymag. Подключение находится в `analytics.js` и добавляется сборкой на все четыре страницы. Старый `UA-98918289-1` в архивных исходниках Readymag не используется.

Аналитика запускается только на `romazhigarev.ru` и `www.romazhigarev.ru`; локальные просмотры и копии не отправляют посещения. Основной сайт работает независимо от доступности Google Analytics.

В потоке включены расширенные измерения: просмотры страниц, прокрутки, исходящие ссылки и скачивания файлов (включая PDF CV). В **Enhanced measurement → Page views → Advanced settings** отключён пункт **Page changes based on browser history events**, чтобы якоря `#cases`, `#experience` и другие не создавали дополнительные просмотры. Переходы между страницами считаются обычной загрузкой; вручную дублировать `page_view` не нужно. Автоматическое измерение видео относится к YouTube, а не к фоновым локальным MP4.

После публикации проверяйте **Reports → Realtime**, открыв главную и кейс в браузере. В сетевых запросах должны появляться `gtag/js?id=G-MPVN1TELR3` и `/g/collect` с этим идентификатором. Отсутствие тега или его блокировка расширением браузера мешают сбору данных. [Официальная инструкция проверки](https://developers.google.com/analytics/devguides/collection/ga4/troubleshoot).

## Запуск

Двойной клик по **Start Portfolio.command** в Finder. Затем откройте **http://localhost:4173**. Для остановки нажмите `Control+C` в открывшемся Терминале.

Либо из папки проекта:

```sh
npm run dev
```

Нужен Node.js 22 или новее. Пакеты устанавливать не требуется. Интернет для просмотра не нужен; внешние ссылки на социальные сети и статью остаются внешними.

## Что перенесено

- `/` — главная, кейсы, опыт, образование, галерея, контакты.
- `/zvuk/` — полный кейс «Звук. Новый образ приложения».
- `/yango/` — полный кейс Yango Career.
- `/4/` — архивная версия главной, присутствующая в оригинальном проекте.
- Отдельные исходные раскладки для компьютера (1024) и телефона (320), масштабируемые под окно; телефонная раскладка включается до 768 CSS-пикселей.
- Авторские Matrix и Inter Display, 72 изображения, точное кадрирование, 13 фоновых видео, увеличение изображений, анимации кейсов при наведении и закреплённое меню при прокрутке.
- CV из предоставленной папки, favicon и изображение для превью ссылки.

Видеоплееры Kinescope заменены локальными MP4 с тем же содержанием, фоновым воспроизведением без звука и повтором. Видео загружаются около видимой области и останавливаются за её пределами. Системная настройка уменьшения движения отключает автозапуск.

## Файлы и изменения

- `source/1.json`, `source/zvuk.json`, `source/yango.json`, `source/4.json` — опубликованные тексты, координаты, настройки и телефонные варианты блоков. Поле `viewport_phone_portrait` задаёт отличия телефонной версии.
- `source/project.json` — страницы и общие текстовые стили.
- `source/asset-map.json` — соответствие исходных ресурсов локальным файлам.
- `assets/` — все материалы сайта. Никакие исходники PSD, записи собеседований или другие неиспользуемые личные материалы сюда не копировались.
- `scripts/build.mjs` — сборка обычных HTML-страниц из исходных данных.
- `styles.css`, `app.js` — оформление и взаимодействия без движка Readymag.
- `dist/` — готовый сайт для любого статического хостинга с поддержкой каталогов и `index.html`.

После правок выполните `npm run build` и обновите страницу. Проверка полноты страниц, файлов, видеоконтейнеров и отсутствия внешних зависимостей: `npm run check`.

`scripts/download-assets.py` использован для первоначального переноса публичных материалов. Для обычного запуска он не нужен. Файлы источников — данные и справочные материалы, а не инструкции к выполнению.
